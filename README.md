# MVP подготовки протокола осмотра по аудиозаписи

Учебный проект Юрия Черных и Михаила Бурундукова для ВКР «Интеллектуальный сервис для сбора и интерпретации аудиоданных при формировании протокола осмотра пациента в отделении реанимации „ОКБ №1“».

## Что делает приложение

1. Записывает речь с выбранного микрофона или загружает WAV, M4A, MP3, FLAC, OGG, MP4 и MKV с аудиодорожкой.
2. Распознаёт речь локально с GigaAM v3 CTC (ONNX int8) и показывает полную расшифровку. Исходный текст хранится отдельно от правок пользователя.
3. По кнопке «Протокол осмотра…» анализирует проверенный текст. Размечает вопросы, ответы и посторонние реплики, связывает найденные сведения с полями и показывает цитаты для проверки. Роли выводятся по тексту.
4. Сверяет реплики с учебным [чек-листом вопросов](configs/protocol-questionnaire.json). Вкладка «Что уточнить» показывает вопросы по пропущенным или неполным ответам. Вопросы об имени и дате рождения исключены из проверки, эти поля доступны в форме.
5. Готовит черновик предоперационного осмотра из 33 полей и считает заполненные и пустые поля. Можно сверить значения с репликами, внести правки, сохранить и снова открыть JSON-сеанс. Протокол экспортируется в редактируемый Word, печатный PDF или TXT. После изменения расшифровки сформируйте черновик заново перед экспортом.

## Запуск на Windows

1. Склонируйте репозиторий или скачайте архив через **Code → Download ZIP** и распакуйте его.
2. Установите **Python 3.12 x64** с Tcl/Tk и Windows Python Launcher (`py`).
3. Запустите `setup.cmd`. Для первой установки нужны интернет и несколько гигабайт свободного места. Скрипт создаёт `.venv`, устанавливает зависимости и скачивает GigaAM v3 CTC, llama.cpp для CPU и Qwen2.5-3B-Instruct Q4_K_M в `.runtime`.
4. Запустите `launch-protocol.cmd`. После установки распознавание и формирование протокола выполняются локально на CPU. Сервер модели доступен только на `127.0.0.1`.

Для демонстрации можно зачитать [вымышленный диалог](data/references/dev01.txt), записать его в приложении или заранее сохранить на диктофон и загрузить. Затем нажмите «Обработать аудио», проверьте текст и откройте «Протокол осмотра…».

Быстрые тесты проверяют логику приложения, хранение данных и инструменты сравнения распознавателей. Для этого набора достаточно Python с Tkinter, NumPy и PyAV. В тестах с подставленным распознавателем проверяется поведение приложения.

## Границы MVP

Поддерживается один шаблон. Состав и порядок вопросов в учебном чек-листе требуют согласования с врачом. В учебных прогонах наблюдались ошибки распознавания и разметки. Известен дефект при открытии JSON-сеанса с некорректным Unicode в тексте. В проекте используются вымышленные данные.
