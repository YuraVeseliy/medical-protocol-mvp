# MVP подготовки протокола осмотра по аудиозаписи

Учебный проект Юрия Черных и Михаила Бурундукова для ВКР «Интеллектуальный сервис для сбора и интерпретации аудиоданных при формировании протокола осмотра пациента в отделении реанимации „ОКБ №1“».

## Что делает приложение

1. Записывает речь с выбранного микрофона или загружает WAV, M4A, MP3, FLAC, OGG, MP4 и MKV с аудиодорожкой.
2. Распознаёт речь локально и показывает полную расшифровку. Исходный текст хранится отдельно от правок пользователя.
3. По кнопке «Протокол осмотра…» анализирует проверенный текст. Размечает вопросы, ответы и посторонние реплики, связывает найденные сведения с полями и показывает цитаты для проверки. Роли выводятся по тексту.
4. Готовит черновик предоперационного осмотра анестезиологом-реаниматологом из 17 полей. Для числовых полей применяется формат формы. Поля без сведений остаются пустыми, неоднозначные помечаются для уточнения. Для учебной проверки полноты выделены жалобы, анамнез болезни и аллергологический анамнез.
5. Позволяет сверить и отредактировать черновик, сохранить и снова открыть JSON-сеанс, экспортировать расшифровку и протокол в TXT. Если расшифровка изменилась после формирования черновика, перед экспортом протокол нужно сформировать заново.

## Запуск на Windows

1. Склонируйте репозиторий или скачайте архив через **Code → Download ZIP** и распакуйте его.
2. Установите **Python 3.12 x64** с Tcl/Tk и Windows Python Launcher (`py`).
3. Запустите `setup.cmd`. Для первой установки нужны интернет и несколько гигабайт свободного места. Скрипт создаёт `.venv`, устанавливает зависимости и скачивает Whisper Small, llama.cpp для CPU и Qwen2.5-3B-Instruct Q4_K_M в `.runtime`.
4. Запустите `launch-protocol.cmd`. После установки распознавание и формирование протокола выполняются локально на CPU. Сервер модели доступен только на `127.0.0.1`.

Для демонстрации можно зачитать [вымышленный диалог](data/references/dev01.txt), записать его в приложении или заранее сохранить на диктофон и загрузить. Затем нажмите «Обработать аудио», проверьте текст и откройте «Протокол осмотра…».

Пусковой файл выбирает Whisper Small. Другие распознаватели доступны после отдельной установки. Например, чтобы добавить GigaAM v3 CTC, выполните команду:

```powershell
.\.venv\Scripts\python.exe scripts\setup_asr_models.py --model gigaam-ctc
```

## Исходный код и проверки

| Файл | За что отвечает |
| --- | --- |
| [gui.py](audio_mvp/gui.py), [recording.py](audio_mvp/recording.py) | Окно приложения и запись |
| [audio.py](audio_mvp/audio.py), [providers.py](audio_mvp/providers.py) | Декодирование, разбиение аудио и запуск ASR |
| [session.py](audio_mvp/session.py), [storage.py](audio_mvp/storage.py) | Состояние сеанса, JSON и экспорт |
| [protocol_inference.py](audio_mvp/protocol_inference.py) | Вызов локальной языковой модели и выделение сведений |
| [protocol.py](audio_mvp/protocol.py), [protocol_gui.py](audio_mvp/protocol_gui.py) | Схема формы, проверка полноты и редактирование черновика |

```powershell
.\.venv\Scripts\python.exe scripts\check.py
```

Быстрые тесты проверяют логику приложения, хранение данных и инструменты сравнения распознавателей. Для этого набора достаточно Python с Tkinter, NumPy и PyAV. В тестах с подставленным распознавателем проверяется поведение приложения.

## Границы MVP

Поддерживается один шаблон. Полнота и корректность сведений требуют проверки специалистом. В учебных прогонах наблюдались ошибки распознавания слов и разметки вопросов и ответов. Известен дефект при открытии JSON-сеанса с некорректным Unicode в тексте. В проекте используются вымышленные данные.
